# AGENTS.md

## Цель
Разработать desktop-приложение под Windows на Python 3.10+ для пакетного преобразования аудиофайлов в текст с помощью локального Whisper `small`.

Приложение должно:
- работать через GUI;
- выполнять распознавание локально;
- не использовать OpenAI API;
- не отправлять аудио или текст в интернет;
- поддерживать пакетную обработку.

Сеть разрешена только для скачивания аудиофайлов по URL в соответствующем режиме.

---

## Обязательные режимы работы

### 1. Список URL
Приложение должно:
- принимать список URL аудиофайлов;
- скачивать каждый файл;
- распознавать его локально через Whisper `small`;
- сохранять результат в `.txt`;
- показывать статус по каждому URL.

Требования:
- список URL вводится через GUI;
- желательно поддержать загрузку списка из `.txt`;
- ошибка одного URL не должна останавливать весь пакет.

### 2. Папка
Приложение должно:
- принимать путь к папке через GUI;
- находить все поддерживаемые аудиофайлы в этой папке;
- распознавать каждый файл локально через Whisper `small`;
- сохранять результат в `.txt`;
- показывать статус по каждому файлу.

Требования:
- путь к папке должен сохраняться в настройках;
- желательно предусмотреть опцию обработки вложенных папок;
- ошибка одного файла не должна останавливать весь пакет.

---

## Допустимый дополнительный режим
Можно добавить обработку одного файла вручную, но этот режим не заменяет два обязательных пакетных режима.

---

## Основные требования

1. Использовать модель `small`.
2. Поддерживаемые форматы:
    - `mp3`
    - `wav`
    - `m4a`
    - `mp4`
    - `ogg`
    - `flac`
    - `webm`
3. Должен быть выбор языка:
    - `Russian`
    - `English`
    - `Auto detect`
4. Для каждого обработанного аудиофайла должен создаваться отдельный `.txt`.
5. Нужно предусмотреть папку для сохранения результатов.
6. Нужно показывать статус обработки по каждому элементу.
7. Интерфейс не должен зависать во время обработки.
8. Нельзя допускать повторный запуск той же обработки, пока текущая не завершена.

## Интерфейс

В GUI должны быть:
- переключение режима работы:
    - список URL
    - папка
    - опционально один файл
- поле/область ввода URL-списка;
- поле пути к папке;
- кнопка выбора папки;
- выбор языка;
- кнопка запуска обработки;
- список/таблица статусов;
- текстовая область для просмотра результата выбранного элемента;
- строка общего статуса;
- кнопки:
    - сохранить текст;
    - копировать текст;
    - очистить;
    - желательно сохранить все результаты.

Интерфейс должен быть:
- простым;
- понятным обычному пользователю;
- ориентированным на Windows;
- без перегруженности.

## Backend

Выбрать наиболее практичный backend для Windows из:
- `openai-whisper`
- `faster-whisper`
- `whisper.cpp`

Предпочитать **`faster-whisper`**, если он даёт более простую установку и лучшую производительность на Windows.

Перед написанием кода обязательно объяснить:
- какой backend выбран;
- почему выбран именно он;
- какие зависимости нужны;
- какие у решения ограничения.

## Проверка окружения

При запуске приложения проверить:
- доступность backend;
- наличие модели `small`;
- наличие `ffmpeg`, если требуется;
- корректность основных зависимостей;
- доступность папки результатов, если она уже задана.

Если окружение не готово, приложение должно показать понятное сообщение:
- чего не хватает;
- зачем это нужно;
- что установить или настроить.

## Настройки

Нужно хранить в настройках:
- путь к папке для обработки;
- путь к папке результатов;
- язык по умолчанию;
- обрабатывать ли вложенные папки;
- что делать, если `.txt` уже существует:
    - перезаписывать;
    - пропускать;
    - либо переименовывать.

Настройки должны сохраняться между запусками.

## Обработка ошибок

Обязательно обработать:

### Общие
- режим не выбран;
- backend недоступен;
- модель `small` не найдена;
- `ffmpeg` не найден;
- ошибка инициализации;
- ошибка сохранения настроек.

### URL
- список URL пуст;
- URL некорректный;
- файл недоступен;
- ошибка скачивания;
- загружен не аудиофайл;
- пустой скачанный файл.

### Папка
- папка не указана;
- папка не существует;
- нет прав на чтение;
- в папке нет подходящих файлов;
- ошибка чтения файла.

### Распознавание
- файл повреждён;
- файл пустой;
- формат не поддерживается;
- ошибка транскрибации;
- пустой результат.

### Сохранение
- нет прав на запись;
- папка результатов недоступна;
- недопустимое имя файла;
- ошибка создания `.txt`.

Ошибка одного элемента не должна останавливать весь пакет, если это не критическая системная ошибка.
